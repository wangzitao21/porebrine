这些参数从哪里来，面积怎样更新？

由计算得到：各矿物体积来自守恒化学反应量；光卤石支撑面积来自局部九格体积分数拟合后的固液界面；覆盖率、颗粒尺寸和层厚由下面的几何关系更新。法向拟合避免用两侧体积分数差直接估计斜界面时虚增的阶梯接触面积。

本次指定的形态参数：颗粒初始半径 1.5 µm、接触角 90°；薄层初始全覆盖；多孔层孔隙率 0.35、曲折度 2；致密层孔隙率 0。它们是受控实验条件，尚未由真实岩石实验标定。

仅凭矿物体积分数，不能唯一算出接触面积：相同体积可能是颗粒，也可能是薄层。真实参数可由显微图像中的粒径、接触斑和层厚约束；层孔隙率由孔体积占比估计，有效扩散系数可用扩散实验或微结构计算得到。本模型把 τ 定义为 D水·ε层 / D层，再据此更新传质阻力。

颗粒：V = N·[π(1−cos α)²(2+cos α)/3]·r³；外表面积 Aₒ = N·2π(1−cos α)·r²；接触斑面积 A𝒻 = N·π sin²α·r²。

化学反应更新 V，固定本次试验的 N 与接触角，再计算 r、外表面积和接触斑。N 是连续的群体数量，不是逐颗追踪的整数。共同支撑面上的随机颗粒覆盖率为 Θ = 1 − exp(−ΣA𝒻/A₀)，外表面积再扣除重叠遮蔽。

薄层：δ = V附着 / [A覆盖·(1−ε层)]；有效扩散系数 D层 = D水·ε层/τ。石盐和钾石盐占并排的固定覆盖斑，沿法向生长或溶解改变厚度，某相耗尽后对应覆盖斑消失。

每个化学阶段按新库存更新面积与厚度；几何重构后更新光卤石支撑面积。支撑面缩小或消失时，相关沉淀转入原位置的残留库存，不删除质量，也不会因为后来出现新表面就自动重新附着。

光卤石总通量：A₀·[(1−Θ)j裸露 + Θj覆盖]。覆盖区通量由层厚、扩散与表面 Pitzer 化学联立求得；“有效面积”是同一总通量折算到裸露通量后的等效面积。

层孔隙率和曲折度目前采用输入常数；同一网格中混合覆盖采用平均层厚。颗粒接触区按不可穿透处理，多孔层允许透过。脱离原矿物后的产物仍参与化学与输运，但没有求解力学脱落、裂缝或真实跨网格单晶生长。

初始沉淀是指定的初始库存，未从入口液体中凭空反应生成。初始物质账本包含这些固体。纯光卤石组保持相同的光卤石体积、盐水浓度和边界条件，关闭石盐与钾石盐反应。

速率系数：光卤石 0.05、石盐 0.02、钾石盐 0.01 mol/(m²·s)。覆盖区化学采用局部传质近似；二维流动与三维球冠群体通过等效厚度连接。图像展示网格平均体积分数，不展示单颗晶体的实际轮廓。线性色标默认开启，可单独增强少量沉淀的可见性。
